# 캐릭터 진화 디자인 문서 — 최종 진화까지 (3단계)

> **Summary**: 각 캐릭터의 2단계 진화 라인업 (기본형 → 1차 진화형 → 최종 진화형)과 조건, GPT 이미지 생성 프롬프트
>
> **Project**: desktop-tamagotchi
> **Date**: 2026-07-28
> **Status**: 최종 진화형 아트 생성 대기
> **연관**: [characters.md](characters.md) · [chatgpt-image-prompts.md](chatgpt-image-prompts.md) · Plan FR-15

## 1. 진화 컨셉

**테마: "직장인의 성장 서사"**
- 기본형: 신입/입문자
- 1차 진화: 자기 자리를 잡은 프로
- 최종 진화: 그 길의 정점 (창업·회장·달인)

| 규칙 | 내용 |
|------|------|
| 시점 | **업무 활동 조건 충족** 시 (부화 이후 언제든) |
| 방향 | 캐릭터당 1차·최종 2단계 진화 |
| 크기 | 게임 캔버스 256px 동일. 최종형은 살짝 여유롭고 위엄있는 실루엣 |
| 정체성 | 얼굴·색 팔레트 유지, 소품·자세로 성장 표현 |

## 2. 진화 조건 (활동 지표)

### 1차 진화 (기본형 → 1차)

| 캐릭터 | 조건 | 값 |
|--------|------|-----|
| 🍡 모찌 → 프로찌 | 키보드 타이핑 | 30,000회 |
| 🐤 삐약 → 꼬꼬 | 서로 다른 날 출근 | 5일 |
| 🐹 햄찌 → 함장님 | 먹이+간식 케어 | 40회 |
| 🐻 꾸벅 → 꿀잠도사 | 뽀모도로 완료 | 10회 |
| 🐈 나른냥 → 자유냥 | 쓰다듬기 | 100회 |
| ☕ 콩이 → 라떼님 | 마우스 클릭 | 20,000회 |
| 🐙 문덕 → 문팀장 | 할 일 완료 | 30개 |
| 🐢 거부장 → 거이사님 | 활성 시간 | 100시간 |
| 🔥 불금조 → 불사조 | 금요일 활성 | 8시간 |
| 👻 스르륵 → 스르신 | 정시퇴근 | 3회 |
| 🥕 당근이 → 다이어토 | 연속 출근 | 3일 |

### 최종 진화 (1차 → 최종) — 기존 지표 유지, 임계값 상향

| 캐릭터 | 최종형 | 조건 | 값 |
|--------|-------|------|-----|
| 프로찌 → **회찌** | (회장 슬라임) | 키보드 타이핑 | 100,000회 |
| 꼬꼬 → **꼬끼오** | (팀장 닭) | 서로 다른 날 출근 | 20일 |
| 함장님 → **햄왕** | (프랜차이즈 오너) | 먹이+간식 케어 | 150회 |
| 꿀잠도사 → **꿈신** | (잠의 신) | 뽀모도로 완료 | 40회 |
| 자유냥 → **여행냥** | (디지털 노마드) | 쓰다듬기 | 400회 |
| 라떼님 → **카페왕** | (카페 사장) | 마우스 클릭 | 80,000회 |
| 문팀장 → **문사장** | (창업 성공) | 할 일 완료 | 100개 |
| 거이사님 → **거회장** | (명예 회장) | 활성 시간 | 300시간 |
| 불사조 → **영원조** | (워라밸 신) | 금요일 활성 | 30시간 |
| 스르신 → **자유혼** | (완전 해방) | 정시퇴근 | 10회 |
| 다이어토 → **헬토** | (헬창 최종) | 연속 출근 | 14일 |

**개인정보 원칙**: 키보드/마우스는 `GetAsyncKeyState` 폴링으로 개수만 집계 (어떤 키·좌표는 저장/기록 없음).

## 3. GPT 요청 팁 (중요)

1. **1차 진화형 이미지를 반드시 첨부**하고 "이 캐릭터의 최종 진화형"으로 요청 — 얼굴·정체성 일관성의 핵심
2. 스타일·기술 조건은 [chatgpt-image-prompts.md](chatgpt-image-prompts.md)의 **공통 스타일 블록**을 먼저 붙여넣기 (치비·반짝이 눈·두꺼운 외곽선·투명 PNG)
3. **4열×2행 포즈 시트** 동일 구성: 기본 / 걷기A / 걷기B / 잠 / 신남 / 시무룩 / 아픔 / 먹기
4. 완성 파일은 `design/` 폴더에 `최종_캐릭터이름.png`로 저장 (예: `최종_회찌.png`)

## 4. 최종 진화형 10종

### 4.1 회찌 (프로찌의 최종형)

| 항목 | 내용 |
|------|------|
| 스토리 | 승승장구 끝에 자기 이름을 건 회사를 창업. 슬라임계의 CEO |
| 외형 변화 | 프로찌의 동그란 안경은 그대로. 몸통 앞에 **광택 있는 검은 정장 재킷** 실루엣, 목에 나비타이. 이마 옆에 회사 로고 배지 하나. 자세는 여유롭고 몸이 살짝 더 커짐 |
| 성격 | 여전히 부드럽지만 완전한 자신감. "다 잘될 거야, 내가 봤어" 스타일 |

```
(프로찌 이미지 첨부 후) 이 캐릭터의 최종 진화형 "회찌"의 포즈 시트를 만들어줘:
프로찌의 최종 형태로 슬라임 CEO가 된 모습. 동그란 안경은 그대로 유지.
몸통 앞에 광택 있는 검은 정장 재킷 실루엣, 목에는 넥타이 대신 작은 나비타이.
이마 옆에 작고 심플한 회사 로고 배지 하나. 자세는 여유롭고 자신감 있음.
얼굴과 분홍 색감은 원본과 똑같이 유지해줘.
```

### 4.0 다이어토 (당근이의 1차 진화)

> ※ 참고: 당근이(기본형)와 다이어토(1차)의 프롬프트는 첫 생성이므로 원본 이미지 첨부 없이도 됩니다. 최종형(헬토)만 다이어토 이미지 첨부 필요.

## 5. 게임 적용 계획

| 항목 | 내용 |
|------|------|
| 파일 위치 | `assets/sprites/chars/<종족>_evolved2/` (8포즈, 기본과 동일 규격) |
